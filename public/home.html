  • Works without metadata. Return page, customer history, identified email and checkout timing as fallbacks.
  • Every payment is explained. The Journey tab shows exactly how each one was matched.
  • Your payment stack. Dodo Payments built in, plus a generic API for Stripe, Lemon Squeezy, Polar and anything else.

Deploy

Your server. Your data. One afternoon.

Node 22.13+ or Docker. No build service, no database admin, no monthly bill. The first boot creates the database and runs every migration automatically.

Docker

recommended
git clone https://github.com/rahulxdevv/kestrel.git
cd kestrel
docker build -t kestrel .

docker run -d --name kestrel -p 3000:3000 \
  -v kestrel-data:/data \
  -e ADMIN_PASSWORD='a-strong-password' \
  -e SESSION_SECRET="$(openssl rand -hex 32)" \
  kestrel

Open http://localhost:3000/app. Everything lives in the volume at /data.

Dokploy / Coolify

compose
services:
  kestrel:
    build: .
    restart: unless-stopped
    ports: ["3000:3000"]
    environment:
      ADMIN_PASSWORD: ${ADMIN_PASSWORD}
      SESSION_SECRET: ${SESSION_SECRET}
    volumes:
      - kestrel-data:/data

volumes:
  kestrel-data:

Build type: Dockerfile. Add a persistent volume at /data and point your domain at port 3000.

Render

blueprint
# render.yaml is included in the repo
services:
  - type: web
    name: kestrel
    runtime: docker
    plan: starter
    healthCheckPath: /api/health
    disk:
      name: kestrel-data
      mountPath: /data
      sizeGB: 1

Render needs a persistent disk for the SQLite file; without it the database resets on every deploy.

VPS / Cloudflare

both
# Any VPS with Node 22.13+
npm ci && npm run build
ADMIN_PASSWORD='…' SESSION_SECRET='…' npm start

# Cloudflare Workers (optional)
npx wrangler d1 create kestrel
npm run deploy:cloudflare

Put Caddy or Nginx in front for HTTPS. Both runtimes share the same code and schema.

FAQ

Questions worth asking

Is Kestrel really free?

Yes. MIT licensed, self-hosted, no seat limits, no event limits, no feature gates. You pay for your own server if you don’t already have one.

Do I need a cookie banner?

Kestrel only uses first-party cookies on your own domain to recognise a returning visitor and keep a session together. There are no third-party cookies and no cross-site tracking. Whether you need a banner depends on your jurisdiction and legal advice, but the data is far smaller, and it never leaves your server.

Can I use Postgres or MySQL?

Not today. Kestrel is deliberately SQLite-first: one file, zero operations, fast on a $4 VPS and easy to back up. A managed Postgres adapter is on the roadmap.

How do I get visitor countries on a VPS?

Put Cloudflare in front of your domain (free), or use a proxy that adds geo headers (Caddy with the geo module, Traefik + GeoIP, Vercel). Without geo headers Kestrel simply leaves the country empty; nothing breaks.

Does it work with Stripe?

Yes, through the generic payments API: post a small JSON payload from your webhook with the visitor id, amount and email. Dodo Payments has a native, signature-verified webhook.

Can I keep the Cloudflare deployment?

Yes. The repo still ships a Worker entry, D1 migrations and wrangler config. Run npm run deploy:cloudflare and you get the same dashboard on Workers, free.

Will it handle my traffic?

On SQLite with WAL mode, a small VPS handles millions of events per month comfortably. The dashboard uses pre-aggregated SQL queries with indexes and the tracker batches engaged-time pings, so there is no scanning of raw events on page load.

How do I back up or move servers?

Copy data/kestrel.db (plus the WAL files while stopped, or use sqlite3 .backup) and mount it on the new host. The schema migrates itself on boot.
